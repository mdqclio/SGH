## Migración — apuestas movidas de club-level a carrera-level

### apuestas_carrera_level
Aplicada vía MCP (apply_migration).

```sql
ALTER TABLE carreras ADD COLUMN IF NOT EXISTS apuestas TEXT[] DEFAULT ARRAY[]::TEXT[];
ALTER TABLE clubs DROP COLUMN IF EXISTS apuestas_simples;
```

**Motivo:** Las apuestas simples son específicas de cada carrera (una puede habilitar Ganador+Exacta, otra solo Ganador), no del club completo. Se mueve `apuestas_simples` de `clubs` a `carreras.apuestas`. Las combinadas siguen siendo por reunión (`reuniones.apuestas_combinadas`).

**Cambios en frontend:**
- `admin.html`: eliminada la sección "Apuestas simples ofrecidas" y sus funciones.
- `carta-llamados.html`: agregado campo "Apuestas habilitadas" en el modal de cada turno, persistido en `carreras.apuestas`.
- `programa.html`: modal de Apuestas actualizado — combinadas editables arriba, por-carrera read-only abajo con aviso de edición en Carta de Llamados.

## Refactor — comisariato a club-level

### comisariato_club_level
Aplicada vía MCP (apply_migration).

```sql
ALTER TABLE clubs ADD COLUMN IF NOT EXISTS comisariato JSONB DEFAULT '[]'::jsonb;

UPDATE clubs c
SET comisariato = sub.comisariato
FROM (
  SELECT DISTINCT ON (r.club_id) r.club_id, r.comisariato
  FROM reuniones r
  WHERE r.comisariato IS NOT NULL
    AND jsonb_array_length(r.comisariato) > 0
  ORDER BY r.club_id, r.fecha DESC NULLS LAST
) sub
WHERE c.id = sub.club_id
  AND (c.comisariato IS NULL OR jsonb_array_length(c.comisariato) = 0);

ALTER TABLE reuniones DROP COLUMN IF EXISTS comisariato;
```

**Motivo:** El comisariato es fijo del hipódromo (igual que la Comisión de Carreras), no cambia por reunión. Dato existente migrado del registro más reciente por club.

**Cambios en frontend:**
- `admin.html`: sección "Comisariato (stewards del hipódromo)" editable en el modal de edición de club.
- `programa.html`: `openComisionModal()` muestra ambas listas (comisión y comisariato) read-only desde `clubData`. Removidas funciones editables y botón Guardar del modal.
- `reuniones.html`: eliminada toda referencia al comisariato (HTML, funciones, payload).
